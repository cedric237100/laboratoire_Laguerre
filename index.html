Modéliser un circuit sans connaître sa structure.

Un circuit RC à trois étages, des mesures entrée/sortie, et cinq fonctions de Laguerre. Le modèle explique 98,8 % de la sortie, contre 51,7 % pour un modèle du premier ordre. Tout le calcul tient dans un package R, documenté en anglais.

Le problème

Une boîte noire, des mesures.

On envoie un signal aléatoire de paliers ±1 dans un circuit RC à trois étages (constantes de temps 0,5 s, 1 s et 2 s) et on mesure la sortie, avec un peu de bruit. On fait comme si la structure du circuit était inconnue.

Un circuit RC est un filtre : une résistance et un condensateur qui lissent un signal. On en trouve dans les alimentations, l'audio et les capteurs.

Premier réflexe : un modèle du premier ordre, K/(τs+1). Il rate la dynamique.

Fit sur 60 s de données jamais vues

1er ordre51,7 %
Laguerre, N = 598,8 %
p optimal99,5 %

La méthode

Quatre étapes, zéro itération.

ÉTAPE 1

Une base de fonctions

Les fonctions de Laguerre décroissent vers zéro, comme la réponse d'un système réel. Elles sont orthonormées : aucune ne répète l'autre.

ℓₙ(t) = √(2p)·e^(−pt)·Lₙ(2pt)
ÉTAPE 2

Un réseau de filtres

Un filtre passe-bas, puis une chaîne de filtres passe-tout. Le paramètre p règle la vitesse.

Λₙ(s) = √(2p)/(s+p) · ((s−p)/(s+p))ⁿ
ÉTAPE 3

Des moindres carrés

Le modèle est linéaire en cₙ : on résout un système, sans tâtonner.

(XᵀX)·c = Xᵀy
ÉTAPE 4

Un fit honnête

Identification sur 60 s, évaluation sur les 60 s suivantes, jamais vues.

Fit = 100·(1 − ‖y−ŷ‖/‖y−ȳ‖)

01

Le système

Simuler le circuit RC et fabriquer des données bruitées.

etage_rc()Un étage RC discret : filtre passe-bas du premier ordre.

Exact solution of an RC low-pass filter for a piecewise-constant input: state[k+1] = a * state[k] + (1 - a) * e[k] with a = exp(-dt / tau). The output at step k is the state before the update of step k.

etage_rc(e, tau, dt = 0.01)
e
input vector.
tau
time constant of the stage (seconds).
dt
sampling step (seconds).

Returns A numeric vector of the same length as e.

simuler_systeme()Fait traverser un signal par les trois étages en cascade.

The output of each stage is the input of the next one. With three stages the circuit is a third-order low-pass system.

simuler_systeme(u, taus = c(0.5, 1, 2), dt = 0.01)
u
input vector.
taus
time constants of the stages (seconds).
dt
sampling step (seconds).

Returns The output of the last stage, a numeric vector the same length as u.

generer_donnees()Crée l'entrée (paliers ±1) et la sortie bruitée.

Input: random steps of +1 or -1, each held for hold seconds. Output: the circuit output plus Gaussian measurement noise. The random seed makes the results reproducible.

La base de Laguerre

Les fonctions, les polynômes et le réseau de filtres.

Computed with the recurrence L0 = 1, L1 = 1 - x, (i + 1) L(i+1) = (2i + 1 - x) Li - i L(i-1).

regresseurs()Réseau de Laguerre discret : fabrique les colonnes de la matrice X.

A low-pass filter followed by a chain of all-pass filters. Column j of the returned matrix is the output of the j-th stage of the network when the input is u. These columns are the regressors of the least-squares problem.

Returns A matrix with length(u) rows and N columns.

verifier_reseau()Auto-test : le réseau discret est bien orthonormé.

The response of the network to an impulse must be close to the theoretical function \ell_n(t). The network is discrete: its output is read before the state update, which gives a delay of about dt/2, and a discretisation error of about 0.7 percent per stage for dt = 0.01 s. The test therefore checks the relative L2 error against a tolerance.

verifier_reseau(p = 1, N = 6, dt = 0.01, tolerance = 0.10)
p
Laguerre pole.
N
number of stages tested.
dt
sampling step (seconds).
tolerance
maximum accepted relative error.

Returns The largest relative error over the tested stages. The function stops with an error if this value reaches tolerance.

Les résultats

De la moitié du signal à presque tout.

ModèleFit validation
1er ordre (K = 1,23 ; τ = 5,51 s)51,74 %
Laguerre (N = 5, p = 1)98,82 %
Laguerre (N = 5, p ≈ 0,83, optimal)99,46 %
Laguerre (N = 8, p = 1)99,81 %

Mesures : τ = 0,5 / 1 / 2 s, pas 0,01 s, 120 s de données, bruit σ = 0,02, graine 42. Le fit se stabilise vers N ≈ 8. Le laboratoire tire son propre bruit : ses chiffres diffèrent d'environ un point.

Limites

  • Le choix de p compte : trop éloigné de la dynamique du système, le fit chute.
  • La méthode suppose un système linéaire.
  • Les chiffres viennent d'une simulation, pas d'un montage réel.

Ce qui tient bon

  • Le bruit : à σ = 0,5 le fit reste à 96 %, car les moindres carrés lissent.
  • Le calcul est reproductible : lancer_projet() refait toute l'expérience.

Installer et tester

Trois lignes dans RStudio.

1. Installer le package depuis GitHub

install.packages("remotes") remotes::install_github("cedric237100/Transfomer-de-Laguerre-Djomanbe-Lieukap-Cedric-Arnold-")

2. Charger et lancer toute l'expérience

library(laguerreRC) res <- lancer_projet(afficher = FALSE)

3. Essayer d'autres valeurs

lancer_projet(p_ref = 0.5, afficher = FALSE) lancer_projet(N_ref = 8, afficher = FALSE) lancer_projet(sigma = 0.1, afficher = FALSE)

4. Vérifier l'orthonormalité du réseau

verifier_reseau(p = 1, N = 6)

Les figures et les fichiers CSV sont enregistrés dans le dossier sortie/.
